LEVEL 4 DENTAL TRACKER — PUBLISHING NOTES

This folder is ready to publish as a static website.

IMPORTANT:
A public, permanent URL cannot be created from this file alone. It must be uploaded to a hosting account (for example, GitHub Pages). No account credentials are included.

Simple GitHub Pages route:
1. Sign in to GitHub and create a new public repository named level4-dental-tracker.
2. Upload all four files in this folder to the repository root: index.html, manifest.json, sw.js, icon.svg.
3. In repository Settings > Pages, select deployment from the main branch and the root folder, then save.
4. GitHub will show the published website URL.
5. Open that URL in Safari on iPhone, tap Share, then Add to Home Screen.

Your tracker saves entries in the browser storage on that device/browser. Use its backup button regularly. Clearing Safari website data or switching devices may remove locally saved progress; the backup file does not automatically sync between devices.
